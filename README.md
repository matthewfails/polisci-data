# Political Science Data Finder

A searchable guide to datasets for undergraduate research in political science, compiled by Matthew Fails (Oakland University).

- To add or edit sources, see [UPDATING.md](UPDATING.md).
- All sources live in [`site/data/sources.yaml`](site/data/sources.yaml).
- Built with [Hugo](https://gohugo.io/) and deployed to GitHub Pages on every push to `main`.
